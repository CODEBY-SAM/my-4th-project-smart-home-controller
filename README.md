# 🏠 Smart Home Controller

## Project Description

Smart Home Controller is an embedded systems project designed to control and automate home appliances using a microcontroller. The system allows users to control devices such as lights, fans, and other electrical appliances through electronic control mechanisms.

The project demonstrates how a microcontroller can receive input from the user or sensors and control different appliances automatically or manually. It is designed as a basic foundation for home automation and IoT-based smart home systems.

# 🎯 Objectives

- Control home appliances using a microcontroller.
- Automate appliances based on predefined conditions.
- Interface sensors and output devices with the controller.
- Reduce unnecessary power consumption.
- Understand the fundamentals of home automation.
- Develop practical embedded systems skills.

# ⚙️ Main Components

- Arduino/ESP32 Microcontroller
- Relay Module
- LEDs / Bulbs
- Sensors
- Push Buttons
- Jumper Wires
- Breadboard
- Power Supply

# 🔄 Working Principle

1. The microcontroller receives input from sensors or control buttons.
2. The input is processed according to the programmed logic.
3. The controller sends signals to the relay module.
4. The relay switches the connected appliances ON or OFF.
5. The system can automate appliances according to predefined conditions.
